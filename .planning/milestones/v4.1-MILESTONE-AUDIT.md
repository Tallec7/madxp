## Cross-Phase Integration

**Checker:** gsd-integration-checker (2026-05-08)
**Result:** 4/4 flows pass

### Flow 1 — Auto-Launch (Fire OS captive bootstrap)

`dnsmasq.conf` hijacks `firetvcaptiveportal.com` → nginx `firestick-captive.conf` 302 → `wifistub.html` → `wifiredirect.html` → `http://192.168.4.1/` → Angular router → `/api/captive/whoami` via `X-Real-IP` → `receivers.service.js._ipToMac` Map → if assigned: `/display/N`; if not: wait page. **PASS**

### Flow 2 — Assignment (admin assigne MAC depuis dashboard)

`SitesService.getConnectedReceivers()` → `GET /api/sites/:id/connected-receivers` → `socketService.getConnectedReceivers()` → dropdown displays-editor → `assignReceiver()` → `displaysChange.emit()` → `saveDisplays()` → `PATCH /api/sites/:id/displays` → `commandQueueService.sendOrQueue('receiver_assignment_updated')` → sync-agent whitelist → `command-dispatch.js` → `receiversService.assignDisplay()` → `.receivers-cache.json` → Fire Stick prochain poll whoami → `/display/N`. **PASS**

### Flow 3 — Réassignement (atomic swap 1 clic)

displays-editor Réassigner dropdown → `assignReceiver()` atomic: source display `receiver: null` + target display nouvelle MAC → même chaîne que Flow 2 → ancien Fire Stick poll → `displayIndex: null` → page d'attente. **PASS**

### Flow 4 — Observabilité (Fire Stick inconnu → badge ambre)

`receivers.service.js._state` → `getReceivers()` with `displayIndex: v.displayIndex ?? null` (explicite `null`, pas `undefined`) → `state-sync` payload → `socket.service.ts` `unknownFirestickSeenBySite` dedup Map → `kind === 'firestick' && displayIndex === null` → `metricsService.recordHotspotUnknownFirestick(siteId)` + Winston warn + dashboard `isUnknownFirestick()` → badge `.receiver-badge--unknown`. **PASS** _(WARN intégration-checker résolu : `?? null` confirme `null` explicite)_
