## 🍓 Raspberry Pi

Support des modèles Pi 3B+, Pi 4, et **Pi 5** depuis v2.27 :

| Modèle       | Configuration GPU                  |
| ------------ | ---------------------------------- |
| Pi 3B+, Pi 4 | `gpu_mem=256` (automatique)        |
| **Pi 5**     | SwiftShader (rendu logiciel, auto) |

Voir [TROUBLESHOOTING.md](TROUBLESHOOTING.md#5-chromium-crash-aw-snap-error-code-5-après-1-2h-de-boucle-vidéo) pour les détails.
