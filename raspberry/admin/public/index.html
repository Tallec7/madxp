      📡 Réseaux WiFi disponibles

      Sélectionnez un réseau pour connecter le boîtier au WiFi du club. Astuce : Si plusieurs points d'accès ont le même nom (SSID), activez "Fixer le point d'accès" pour éviter les déconnexions.

      Cliquez sur "Scanner" pour afficher les réseaux disponibles.

      🔐 Connexion au réseau

      ⚠️ Réseau mesh détecté

      Ce réseau a plusieurs points d'accès. Le verrouillage BSSID n'est pas recommandé car il peut causer des déconnexions si l'AP verrouillé devient inaccessible.

      Laissez la case décochée pour permettre au dongle WiFi de basculer automatiquement vers l'AP avec le meilleur signal.

      📶 Diagnostic Hotspot WiFi

      Si le réseau WiFi du boîtier (NEOPRO-xxx) n'apparaît pas ou est instable, utilisez ces outils pour diagnostiquer et corriger le problème.

      Cette opération peut prendre jusqu'à 2 minutes (scan des canaux WiFi)...

      ⚠️ Redémarrage nécessaire

      Le canal WiFi a été modifié. Pour appliquer ce changement, le boîtier doit redémarrer (~1 minute d'interruption).

      ⚠️ La TV et la télécommande seront indisponibles pendant le redémarrage.
