Votre TV MadXP est une page web dédiée. Elle doit être ouverte sur l'écran du gymnase en plein écran, et laissée ouverte en permanence.

URL de votre TV
{{ tvUrl }}
  1. Ouvrez un navigateur (Chrome recommandé) sur le PC/TV du gymnase
  2. Collez l'URL ci-dessus et appuyez sur Entrée
  3. Appuyez sur F11 pour le plein écran
  4. Laissez la page ouverte — ne la fermez pas
💡 Utilisez le QR code TV depuis le dashboard pour transférer l'URL sur l'écran du gymnase depuis votre téléphone.

Avec l'option double affichage, deux TVs peuvent diffuser simultanément des contenus différents : l'écran principal joue la boucle habituelle, et un second écran joue une version dédiée (version LED, format vertical, découpe spécifique).

Assigner un contenu spécifique au second écran

  1. Allez dans Ma boucle → Bibliothèque
  2. Survolez la vidéo concernée → ⋮ trois points
  3. Cliquez sur Second écran pour ouvrir le panneau de variante
  4. Uploadez la version destinée au second écran (même nom de catégorie, format adapté)
💡 Si aucune variante n'est assignée à une vidéo, les deux écrans diffusent le même contenu. Les variantes sont indépendantes — remplacer la vidéo principale ne touche pas la variante.

Ouvrir le second écran

Le second écran est un deuxième navigateur ouvert sur la même URL TV. Connectez un second PC ou TV au réseau et ouvrez l'URL — MadXP détecte automatiquement que c'est le second client et lui envoie la variante correspondante.

⚠️ Les deux navigateurs doivent rester ouverts simultanément. Si l'un se déconnecte, il revient en mode principal à la reconnexion.

Dans Ma boucle, la bibliothèque liste toutes vos vidéos disponibles.

Ajouter une vidéo

  1. Cliquez sur + Ajouter du contenu
  2. Glissez-déposez votre fichier ou cliquez pour parcourir
  3. Attendez le statut Prête (icône verte) — quelques secondes à quelques minutes selon la taille
💡 Formats : MP4 (recommandé), MOV · Résolution recommandée : 1920×1080 · Taille max : 500 Mo

Remplacer une vidéo

Pour mettre à jour un fichier sans changer sa place dans la boucle : survolez la vidéo → ⋮ trois points → Remplacer → importez le nouveau fichier.

Supprimer une vidéo

⋮ trois points → Supprimer → confirmer. La vidéo est retirée automatiquement de la boucle.

Placer une vidéo dans la boucle ou une catégorie depuis la bibliothèque

Le bouton + Ajouter sur chaque carte vous évite de faire défiler jusqu'en bas de page pour assigner une vidéo.

  1. Survolez la carte de la vidéo dans la bibliothèque
  2. Cliquez sur + Ajouter (apparaît à droite de la carte)
  3. Un menu liste toutes les destinations disponibles :
    • 🔄 Boucle principale
    • 🎬 Chaque catégorie Action créée dans Ma boucle
    • ⚽ Chaque phase de match (mi-temps, après-match…)
  4. Cliquez sur une destination — la vidéo y est ajoutée instantanément
  5. Un badge coloré sur la carte indique chaque destination où la vidéo est présente
  6. Cliquez sur Enregistrer pour appliquer les changements
💡 Une vidéo déjà présente dans la boucle ne sera pas ajoutée en double. Si le bouton + Ajouter n'apparaît pas, vérifiez qu'aucune catégorie n'est encore créée — le menu reste vide tant qu'il n'y a pas de destination.
⚠️ Si le statut reste Échoué après 5 min : supprimez et réessayez en vérifiant que le fichier est en MP4 et fait moins de 500 Mo.
🔄 Boucle

Vidéos en rotation automatique et continue. Ex : sponsors, annonces club.

🎬 Action

Déclenchée manuellement depuis la télécommande puis retour à la boucle. Ex : animation but.

⚽ Phase de match

Associée à une phase de jeu (mi-temps, après-match). Activée via la session match.

Créer / modifier / supprimer

  • Créer → + Nouvelle catégorie dans Ma boucle, choisir le type, nommer, valider
  • Modifier → cliquer sur le nom ou l'icône crayon
  • Supprimer → icône suppression (les vidéos de la catégorie ne sont pas supprimées)

La boucle (partie inférieure de Ma boucle) est la liste ordonnée des vidéos qui défilent à l'écran.

  • Activer / désactiver → cochez ou décochez la case à côté d'une vidéo
  • Réordonner → glissez-déposez les vidéos (l'ordre = l'ordre de diffusion)

Enregistrer les modifications

Cliquez sur Enregistrer — la modification est prise en compte immédiatement sur l'écran.

💡 Le bouton s'appelle Enregistrer (pas "Déployer") car il n'y a pas de boîtier Pi à synchroniser : la config est mise à jour directement dans le cloud.

La pondération permet de contrôler le temps d'antenne de chaque sponsor dans la boucle. Par défaut, toutes les vidéos ont un poids égal (×1). En augmentant le poids d'un sponsor, ses vidéos reviennent plus souvent.

Régler les poids

  1. Allez dans Ma boucle
  2. Sur chaque vidéo taggée avec un sponsor, vous voyez un contrôle − ×N + accompagné d'un pourcentage
  3. Cliquez + pour augmenter (jusqu'à ×10) ou − pour diminuer (minimum ×1)
  4. Le pourcentage se recalcule en temps réel pour tous les sponsors
  5. Cliquez sur Enregistrer pour appliquer
Sponsor A ×3
75 %
Sponsor B ×1
25 %
💡 La pondération s'applique par sponsor — toutes les vidéos d'un même sponsor partagent le même coefficient. Un sponsor à ×3 face à un sponsor à ×1 obtiendra 75 % du temps d'antenne sponsor.

💡 Le portail sponsor est une page personnalisée que vous pouvez partager à votre partenaire pour qu'il consulte ses statistiques sans avoir de compte MadXP.

La télécommande est une page web — aucune application à installer. Ouvrez le lien ou scannez le QR code fourni par le responsable communication.

Télécommande
{{ remoteUrl }}

Créer un raccourci sur l'écran d'accueil

  • Safari (iOS) : icône Partager → Sur l'écran d'accueil → nommer "Télécommande Match"
  • Chrome (Android) : menu ⋮ → Ajouter à l'écran d'accueil

Entrez votre PIN (4 chiffres) pour accéder aux commandes.

Démarrer la session

  1. Appuyez sur Démarrer un match dans la télécommande
  2. Saisissez l'équipe domicile et l'équipe adverse
  3. Appuyez sur Lancer — la TV passe en affichage match
⏱️ La session se ferme automatiquement après 4 heures d'inactivité ou 24 heures maximum.

Score en direct

  • +1 Domicile / +1 Visiteur → marquer un but
  • −1 → corriger une erreur de saisie

Déclencher une action

  1. Onglet Actions → appuyez sur la vidéo souhaitée
  2. La TV joue la vidéo, puis reprend la diffusion automatiquement

Mi-temps et fin

  1. Onglet Match → Mi-temps → les vidéos de la phase mi-temps s'affichent
  2. Reprendre le match pour la 2ᵉ mi-temps
  3. Terminer le match → score figé dans l'historique

Guide des phases recommandées

30 min avant Boucle "Sponsors" (accueil du public)
Entrée des équipes Action "Animations entrée" ou phase "Échauffement"
Pendant le match Boucle "Sponsors" en fond
But / Temps fort Action "Célébration but"
Mi-temps Phase "Mi-temps" — audience maximale = sponsors prioritaires
Fin de match Boucle "Sponsors" / phase "Après-match"

Changer l'affichage

Onglet Affichage → Boucle (rotation normale), Match (score en direct), Suivant / Précédent pour avancer manuellement, Pause pour figer l'écran.
